Selected engineering projects.

P01

Swarm Robotics System

Master–slave multi-robot communication
PIC16F877AEmbedded C433 MHz RFIR SensorsL298N
Overview

Developed a master–slave swarm robotics system enabling multiple robots to coordinate through RF communication and IR-based line following.

Architecture

Each unit runs on a PIC16F877A. A master node broadcasts commands over a 433 MHz RF link to addressed slave robots, while L298N drivers control the drive motors and onboard IR arrays handle local line-following.

My Contribution

Led a 4-member engineering team; owned the RF communication protocol and firmware architecture for master–slave coordination.

Challenges & Solution

RF interference and keeping slaves synchronized without a shared bus were the core problems — solved with an addressed packet protocol, retries, and per-unit IR threshold tuning.

P02

AHB-to-APB Bridge

RTL design & AMBA protocol conversion
Verilog HDLFSMCadence NCLaunchCadence GenusGPDK45
Overview

Designed an AHB slave interface and an AHB-to-APB bridge in Verilog HDL for AMBA-based SoC architectures, as part of a VLSI design internship.

Architecture

An FSM-based controller translates AHB transfer phases into APB setup and access phases, handling protocol conversion between the high-performance and peripheral buses.

My Contribution

Implemented the RTL and FSM control logic, then verified functional behaviour through simulation and checked timing through synthesis.

Challenges & Solution

Reconciling differing bus timing and transfer types between AHB and APB was addressed with an explicit IDLE / SETUP / ACCESS state machine, verified against edge-case transfers in simulation.

Results

RTL verified functionally correct in Cadence NCLaunch simulation, and synthesized with timing analysis in Cadence Genus.

P03

Automated Seed Sowing Machine

IoT-connected agricultural automation
Arduino UnoESP8266BlynkUltrasonic SensorsL293D
Overview

Designed an automated agricultural system for controlled seed dispensing and remote monitoring using IoT connectivity.

Architecture

An ESP8266 handles Wi-Fi connectivity and reports to the Blynk app, ultrasonic sensors monitor seed levels, and an L293D driver controls the dispensing motor.

My Contribution

Improved automation and seed dispensing efficiency through firmware development on the ESP8266 module.

Challenges & Solution

Dispensing timing and sensor noise were tightened through firmware calibration of the ultrasonic thresholds.
